this.calendar.on('afterRender', () => this.reloadEvents()); est la source de votre problème:

Ce qu'elle fait
Cette ligne crée un écouteur d'événement qui:

Se déclenche chaque fois que le calendrier termine un rendu (afterRender)
Appelle la méthode this.reloadEvents()
La méthode reloadEvents() se termine par this.calendar.render()
Ce qui déclenche un nouvel événement afterRender
Et la boucle recommence sans fin
Pourquoi c'est problématique
Cette boucle infinie:

Surcharge le navigateur avec un rendu continu
Lance des requêtes AJAX constantes vers votre serveur
Empêche toute interaction fluide avec le calendrier
Ignore complètement les changements d'état (case à cocher, etc.)
Solution
Supprimez complètement cette ligne ou remplacez-la par:
// Pas besoin d'écouter afterRender, car les render sont déjà
// explicitement appelés après chaque action importante
// this.calendar.on('afterRender', () => this.reloadEvents());

Vos autres méthodes appellent déjà reloadEvents() et calendar.render() quand c'est nécessaire:

Dans changeView()
Dans saveEvent()
Dans createDuplicateEvent()
Après les actions sur les cases à cocher
Cette modification devrait résoudre vos problèmes d'affichage et rendre l'interface complètement fonctionnelle.
