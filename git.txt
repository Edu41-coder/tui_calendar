Résoudre l'erreur de fusion Git
L'erreur que vous rencontrez est classique : Git refuse de faire un pull car vos fichiers locaux ont été modifiés et seraient écrasés par la mise à jour depuis le dépôt distant.

Solution 2 : Utiliser Git Stash (mise de côté temporaire)

# 1. Mettre de côté vos modifications actuelles
git stash

# 2. Récupérer les modifications du dépôt distant
git pull upstream develop

# 3. Réappliquer vos modifications
git stash pop
# (vous devrez peut-être résoudre des conflits manuellement)

Si vous voulez simplement revenir à un commit précédent
Si vous préférez abandonner complètement le merge et revenir à un état antérieur :

# Identifier les commits précédents
git log --oneline

# Revenir à un commit spécifique
git reset --hard <hash-du-commit>

# Par exemple, pour revenir à 2 commits en arrière
git reset --hard HEAD~2

# Puis forcer le push (ATTENTION: ceci réécrit l'historique)
git push -f upstream develop
